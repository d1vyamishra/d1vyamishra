# Setup Guide — Animated GitHub Profile README

Everything below is already wired to the username **`d1vyamishra`**. Follow these steps once and it's fully live.

## 1. Create the special profile repo
GitHub only turns a README into your profile page if the repo is named **exactly your username**:
1. Create a new **public** repo called `d1vyamishra`
2. (If it already exists, just clone it)

## 2. Add these files
Copy this whole folder's contents into the repo, keeping the structure:

```
d1vyamishra/
├── README.md
├── SETUP.md
├── assets/
│   ├── header.svg
│   ├── avatar.png
│   ├── coding-desk.png
│   └── standing.png
└── .github/
    └── workflows/
        └── snake.yml
```

Commit and push to `main`.

## 3. Turn on the contribution snake
The snake image in the README (`🐍 Contribution Snake` section) is generated by GitHub Actions and pushed to a branch called `output`. To activate it:

1. In your repo, go to **Settings → Actions → General**
2. Under **Workflow permissions**, select **Read and write permissions** → Save
3. Go to the **Actions** tab → select **Generate Snake Animation** → click **Run workflow** (this runs it for the first time; after that it auto-runs daily at midnight UTC)
4. Wait ~1 minute, refresh your repo — a new `output` branch will appear
5. Refresh your profile page — the snake now animates, "eating" your contribution squares

## 4. Everything else is automatic
No setup needed for these — they're generated live on every page view, pulling straight from your GitHub account:
- The typing animation under the banner
- GitHub Stats card, Top Languages card
- Streak stats
- Contribution activity graph
- Profile view counter

## 5. Optional tweaks
- **Header banner** (`assets/header.svg`): edit the `lines` list in the (already-run) generator script if you ever want to change the typed code snippet — or just open the SVG directly and edit the `<text>` content.
- **Colors**: the whole theme uses your existing badge palette (`#ff3fa3`, `#a855f7`, `#8b5cf6`, `#0d0221`) so everything matches — change these hex values across `README.md` if you want a different palette.
- **Images**: `assets/coding-desk.png` and `assets/standing.png` are included in case you want to swap them into other sections (e.g. an "About" panel) later.
